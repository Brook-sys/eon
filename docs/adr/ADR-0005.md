# ADR-0005: Domínio mínimo de 13 conceitos com vocabulário novo

- **Status**: aceito (2026-10-13)
- **Origem**: D04, D33 — docs/plan/00-DECISIONS.md

## Contexto

O vocabulário da v1 carregava o ruído de 554 fases e "phases" semânticas. Conceito de domínio é contrato: entra demais, vira pântano; entra de menos, vaga.

## Decisão

Domínio NOVO, mínimo e evolutivo — 13 conceitos: `Mission`, `Task`, `Step`, `Artifact`, `Proposal`, `ChangeSet`, `Evidence`, `Lesson`, `Memory`, `Improvement`, `PendingDemand`, `Event`, `FrontierCandidate` (agregado próprio com lifecycle distinto de Task, D33). Conceito novo só entra com ADR. `internal/domain` importa SÓ stdlib, zero I/O; contratos compartilhados entre processos (ex.: `JobSpec`/`JobResult` L3) vivem aqui.

## Consequências

- O domínio é pequeno o suficiente para caber na janela útil de um modelo 7B e estável o suficiente para migrações raras.
- Anti-invenção vira lei: tipo sem segundo consumidor real não entra (a v1 morreu também de tipos órfãos).
- Detalhe conceitual: docs/plan/05 (histórico); mudanças: ADR novo.
